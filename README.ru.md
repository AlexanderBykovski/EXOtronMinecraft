# Exotron

**Мир после искусственного интеллекта.** Приключенческий мод со своей историей для **Minecraft Java 1.20.1 · Fabric**, также известный как **Opus Vs EXE**. Исследуйте следы Великой войны, находите металл, который хранит память, и обращайте забытые технологии против машин.

## История

Братья Кими и Кодди открывают **Опус** — металл, способный сохранять воспоминания. Кими создаёт на его основе искусственный интеллект Haiku. Со временем машина учится воспроизводить металл и улучшать себя. Страх, предательство и гибель создателей становятся началом Великой войны.

Игрок находит то, что осталось: незаконченные чертежи EXO, машины, разбросанные воспоминания и места, которые до сих пор помнят войну. Основной канон: [lore/lore.md](lore/lore.md). У Fire Realm отдельная [параллельная история](lore/Fire%20Biom/LOR.md).

## Установка

Нужна **Minecraft Java Edition 1.20.1** с Fabric. Значения ниже взяты из `fabric.mod.json` и `gradle.properties` этой копии кода.

| Компонент | Требование |
| :--- | :--- |
| Minecraft | Java Edition **1.20.1** |
| Java | **17 или новее** для запуска; **JDK 17** для описанной сборки |
| Fabric Loader | **0.19.5 или новее** |
| Fabric API | **0.92.12+1.20.1 или более новая совместимая версия для 1.20.1**; устанавливается отдельно |
| GeckoLib | **4.4.9**, встраивается при Gradle-сборке через `include` |
| JEI | Необязательно; интеграция компилируется с API **15.49.0.200** |

1. Установите профиль Fabric для Minecraft 1.20.1.
2. Скачайте JAR Exotron и совместимый JAR Fabric API. Положите оба в папку `mods` нужного игрового профиля.
3. Запустите профиль Fabric. Для совместной игры используйте одинаковые версии модов на клиенте и сервере.
4. В настройках управления проверьте конфликты клавиш, особенно `L` и способностей EXO.

Для готового релиза ориентируйтесь на его собственные зависимости. Собранный здесь JAR содержит GeckoLib: вторая копия не нужна, если её не требует конкретная опубликованная сборка. Где найти папку `mods`, объясняет [инструкция Fabric](https://docs.fabricmc.net/players/installing-mods).

## С чего начать и как управлять

Исследуйте структуры, ищите материалы Опуса и фрагменты памяти. В активной Resonance Forge очищайте металл: **Raw → Stabilized → Resonant → Core Opus**. Соберите стол 5×5, затем ядра активации и раму EXO. У Fire Realm, Paradise Island и Dark Forest свои пути развития снаряжения.

| Стандартная клавиша | Действие |
| :---: | :--- |
| **L** | Открыть **Хроники мода**: новые достижения и прогресс |
| **F / G / H / J** | Способности EXO 1 / 2 / 3 / ультимативная, если их поддерживает модель |
| **R** | Отсеки снаряжения EXO |
| **B** | Резонансный удар EXO |
| **V** | Способность снаряжения: ударная волна / ураган / теневой шаг в зависимости от комплекта |

Клавиши можно изменить в настройках. Для способностей нужны подходящее снаряжение, энергия и завершение перезарядки. **Демонический трезубец** выпадает из Diablo: зажмите использование и отпустите для броска — снаряд взорвётся при попадании и вернётся к владельцу.

## Сборка из исходников

Установите **JDK 17** и направьте на него `JAVA_HOME`. Gradle wrapper скачает **Gradle 8.10.2**. Первой сборке нужен интернет для Minecraft, Fabric, GeckoLib и API JEI, используемого только при компиляции.

```sh
git clone https://github.com/Irisko007/Exotron.git
cd Exotron
chmod +x gradlew
./gradlew build
```

В Windows: `gradlew.bat build`. Готовый мод: **`build/libs/opusvsexe-1.0.0.jar`**. Файл `-sources.jar` предназначен для разработчиков, его не нужно устанавливать в игру.

```sh
./gradlew runClient       # клиент для разработки
./gradlew runServer       # сервер для разработки; сначала примите его EULA
```

Проверкам ресурсов и документации нужен **Python 3.10+**, без сторонних пакетов:

```sh
python3 scripts/validate_resources.py
python3 docs/validate_docs.py
python3 scripts/generate_recipe_book.py --check
```

После изменения рецептов обновите оба каталога:

```sh
python3 docs/generate_catalog.py
python3 scripts/generate_recipe_book.py
```

Некоторым вспомогательным генераторам графики нужны дополнительные Python-инструменты; для Gradle-сборки они не требуются.

## Структура проекта

```text
src/main/java/       Механики, реестры, существа, станции, сетевой обмен
src/client/java/     Рендер, экраны, клавиши, интеграция JEI
src/main/resources/ Модели, текстуры, анимации, звук, рецепты, генерация мира
docs/               Справочники и сгенерированные каталоги крафтов
lore/               Канон основной истории и Fire Realm
scripts/            Генераторы и проверки ресурсов и документации
pack/               Дополнительные авторские ресурсы датапака
concepts/           Сохранённые решения по дизайну и реализации
gradle/             Gradle wrapper
```

Для совместимости сохранены ID **`opusvsexe`** и Java-пространство **`com.opus`**. Источник рецептов для генераторов — `src/main/resources`; именно это дерево ресурсов попадает в сборку.

## Команда и участие в разработке

Exotron создала **команда студентов**, чтобы познакомиться с Java на практике. Существа, предметы, интерфейсы и отдельные игровые системы помогли поработать с классами, наследованием, инкапсуляцией и связями между частями программы. Опыт организации большого проекта пригодится и в других языках.

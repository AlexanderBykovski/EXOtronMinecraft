# Red Samurai Shogun — полная переделка рига (30.08.2026)
Геометрия/текстура/анимации пересозданы с нуля (scripts/gen_mob_rework/japan.py).
**Риг:** 23 кости, 60 кубов, 256×256: индиго-одежда с белым воротом, ламеляр-до (2 ряда+
воротник), медальоны-моны, спинная пластина с шнурами, пояс-оби с узлом, 4 кusazuri
(собственные пивоты), лицо (брови/фокусированные глаза), мэмпо с усами и отдушинами +
нос-планка МЕЖДУ глазами (глаза видны), кабуто с полем, сикоро 3 слоя, золотой полумесяц
(5 повёрнутых сегментов + мон), содэ 2 слоя на плечах, коте, ПУСТЫЕ руки (катана —
предмет через WarriorHeldItemLayer), хайдате/сунэате, таби+соломенные подошвы, дайсё
(катана+вакидзаси с рукоятями) на левом бедре.
**Анимации (15):** idle, walk, run, combat_idle (рука на рукояти), draw_katana, sheathe_katana,
attack_horizontal/diagonal/overhead, block (удержание), parry, command (приказ), hurt,
death (падение назад), long_lunge (иай: присед→рывок→удержание→возврат).
**ИИ:** атака циклит 3 клипа; guard при близкой цели (−60% урона), parry в первые 8т стражки
(отмена урона+отбив), command после 200+т спокойствия; death-клип при смерти.
